# 隐私说明

本说明适用于仓库中的 Toby 中文版 Chrome 扩展代码。Fork、修改版和其他发布者需要按自身实际行为更新说明。

## 处理的数据

扩展会读取当前 Chrome 窗口中 HTTP/HTTPS 网页的标题和网址，以便用户选择、整理和保存标签。已保存的数据包括空间名称、合集名称、颜色、星标、链接标题、链接网址、排列顺序及本地数据版本信息。

扩展没有读取完整浏览历史的权限，不提供广告追踪或使用统计上报。当前窗口列表不会作为浏览历史自动上传。

## 本地存储

- 扩展数据仅保存于当前 Chrome 配置的 `chrome.storage.local`，不读取或写入账户同步存储。
- 本项目没有数据接收服务器，不要求注册应用账号，也不提供自动跨设备同步。换电脑需要用户自行导出、传递和导入 JSON 文件。
- 公开源码不包含用户在浏览器中保存的数据。
- 普通浏览器预览的数据保存在预览站点的 localStorage，与扩展数据分开保存。
- 拖入合集后隐藏的右侧标签，其标签编号和网址临时记录在本机 `chrome.storage.session`，用于保持管理页之间的显示一致；浏览器退出后清除，不会进入 JSON 备份。
- 早期开发版曾使用 Chrome 账户同步。升级不会自动清除旧版留下的账户副本；仍在运行的旧版应更新或停用。

## 网站图标与外部连接

扩展使用 Chrome 的网站图标接口显示 logo。普通浏览器预览会直接向相应网站请求 `/favicon.ico`，该网站可能接收到 IP 地址等正常网络请求信息；预览图标请求设置了不发送 Referrer。点击保存的链接会打开对应网站，之后的交互适用该网站的政策。

本项目不使用第三方 favicon 聚合服务。

## 导出、删除与卸载

用户可以在设置中将可见内容导出为 JSON 文件。导出文件由用户自行保存，可能包含私人标题或网址，不应直接上传到公开 Issue。

用户可以删除本机空间、合集和链接。卸载扩展或删除浏览器配置会清除本地数据，用户自行保存的备份文件需要分别管理。请在卸载或改变扩展 ID 前导出所需数据。

## 权限用途

| 权限      | 用途                                   |
| --------- | -------------------------------------- |
| `storage` | 本地保存空间、合集和标签               |
| `tabs`    | 读取当前窗口标签的标题、网址并管理标签 |
| `favicon` | 读取 Chrome 提供的网站图标             |
